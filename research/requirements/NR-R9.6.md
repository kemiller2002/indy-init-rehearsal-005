# NR-R9.6

Derived from baseline requirement `R9.6` (URL-addressable views). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Statement |
|---|---|
| R9.6-O1 | Every screen and every addressable thing has a URL, and pasting that URL into another browser opens the same view. |
| R9.6-O2 | Addressable things are investigations, hypotheses, evidence items, unknowns, assumptions, contradictions, actions and experiments, findings, causes, corrective actions, verifications, counterfactual branches, historical versions and reports. |
| R9.6-O3 | The URL also carries the view's navigable state: the selected version or comparison pair, filters, sort, search, tab and page. |
| R9.6-O4 | This is the portfolio deep-linking standard (Praxis SAF-URL-1..10), and the route table is in [Screen Contracts](SCREEN-CONTRACTS.md#url-contract). |
