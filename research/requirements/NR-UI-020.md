# NR-UI-020

Derived from baseline requirement `UI-020` (Navigation and information architecture). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Statement |
|---|---|
| UI-020-O1 | Provide clear, accessible top-level navigation to Investigations, Administration, and Settings. |
| UI-020-O2 | Investigation workflow actions remain in investigation context; operational information belongs in Administration; configurable preferences belong in Settings. |
| UI-020-O3 | Navigation must work on desktop, iPad, mobile, keyboard, and assistive technology, with an identifiable active page and sensible narrow-viewport behavior. |
| UI-020-O4 | Do not use an undifferentiated dashboard as a substitute for these destinations. |
