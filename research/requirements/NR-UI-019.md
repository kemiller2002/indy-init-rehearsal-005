# NR-UI-019

Derived from baseline requirement `UI-019` (Dedicated Settings page). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Acceptance criterion |
|---|---|
| UI-019-O3 | Distinguish a preference from a verified external connection. |

| ID | Statement |
|---|---|
| UI-019-O1 | Provide a separately navigable Settings page for user-adjustable preferences and configuration, distinct from Administration and investigation views. |
| UI-019-O2 | Include only supported settings, such as appearance/theme, accessibility or display preferences, and provider connection preferences where authorized. |
| UI-019-O4 | Do not expose controls that cannot be honored. |
| UI-019-O5 | Define persistence and scope of each setting (session, device, or account), show effective values, and avoid saving credentials in local storage or displaying tokens. |
| UI-019-O6 | Provider authentication and configuration must respect the established security and read-only scope contracts. |
