# NR-ADRP-003

Derived from baseline requirement `ADRP-003` (Locked UI composition default). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Statement |
|---|---|
| ADRP-003-O1 | Default shell: responsive top application bar with identity/sync indicator; desktop/iPad navigation rail or tabs; investigation header showing lifecycle, blockers, and next legal action; main content region; contextual detail panel; mobile stacked layout. |
| ADRP-003-O2 | Overview presents observation, active hypotheses, contradictions, obligations, and next action before secondary history. |
| ADRP-003-O3 | Prefer Forma components; do not introduce an independent design system. |
| ADRP-003-O4 | CSS handles layout and loading indicator; no new JS layout framework. |
| ADRP-003-O5 | Accessibility and responsive obligations override pixel choices. |
