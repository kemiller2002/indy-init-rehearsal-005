# NR-R9.8

Derived from baseline requirement `R9.8` (Missing, superseded or forbidden targets). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Statement |
|---|---|
| R9.8-O1 | A URL naming an entity that does not exist, or a repository the user cannot read, shows a not-found or not-permitted state with a way back to the investigation or home. |
| R9.8-O2 | It never shows a blank page and never shows a different investigation or record. |
| R9.8-O3 | A superseded or rejected entity is still shown as such, because history is never deleted (R2.4). |
