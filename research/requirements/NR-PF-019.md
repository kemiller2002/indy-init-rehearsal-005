# NR-PF-019

Derived from baseline requirement `PF-019` (Local-first workflow). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Acceptance criterion |
|---|---|
| PF-019-O1 | During development, agents should run the smallest relevant deterministic tests first, batch integration checks at meaningful checkpoints, and run the complete live/deployed suite before release. |
| PF-019-O2 | Never skip a test required by an impacted risk or dependency. |
