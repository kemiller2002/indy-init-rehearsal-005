# NR-UI-007

Derived from baseline requirement `UI-007` (Search and filtering). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Statement |
|---|---|
| UI-007-O1 | Support search across investigation titles and, where indexed, observations, evidence, hypotheses, and findings. |
| UI-007-O2 | Provide filters for lifecycle, unresolved contradictions, dates, and severity only where severity exists. |
| UI-007-O3 | Show result counts, highlighted matched text without altering original records, clear filters, no-results guidance, and keyboard access. |
| UI-007-O4 | Search results MUST link to the correct entity. |
| UI-007-O5 | Do not index confidential working data in external services without explicit authorization. |
