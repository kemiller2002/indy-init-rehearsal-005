# RQ-CAUSA-2026-0412

Derived from baseline requirement `UI-029` (Two-level navigation and responsive application shell). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Statement |
|---|---|
| UI-029-O1 | The application shell MUST expose persistent, distinct primary destinations: Investigations, Administration, and Settings (UI-020). |
| UI-029-O2 | Within an investigation, secondary navigation MUST include Overview, Causal Analysis, Evidence, Hypotheses, Timeline, and Corrective Actions where supported. |
| UI-029-O3 | Indicate current destination and preserve accessible focus/navigation on desktop, iPad, and mobile. |
| UI-029-O4 | Do not flatten system settings into an investigation disclosure or use one oversized navigation list for both global and investigation-specific destinations. |
