# NR-UI-009

Derived from baseline requirement `UI-009` (Folio reports and export). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Acceptance criterion |
|---|---|
| UI-009-O4 | Export MUST NOT invent a verified conclusion. |

| ID | Statement |
|---|---|
| UI-009-O1 | Provide interim and final investigation reports with title, lifecycle, chronology, findings, evidence provenance, supporting/contradicting hypotheses, causal conclusions, unresolved unknowns, corrective actions, and verification outcome when present. |
| UI-009-O2 | Include report generation timestamp and investigation/event version. |
| UI-009-O3 | Support print-friendly rendering and PDF via browser print or supported Folio output. |
| UI-009-O5 | Redact sensitive data according to authorization; provide an accessible print preview. |
