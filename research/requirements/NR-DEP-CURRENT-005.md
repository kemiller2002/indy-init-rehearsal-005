# NR-DEP-CURRENT-005

Derived from baseline requirement `DEP-CURRENT-005` (Block on incompatibility). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Statement |
|---|---|
| DEP-CURRENT-005-O1 | If the latest candidate is incompatible, open a defect-class record identifying producer, consumer, contract and reproduction. |
| DEP-CURRENT-005-O2 | Fix the integration or obtain an explicit exception. |
| DEP-CURRENT-005-O3 | A fallback to an older release is never automatic, and must record its scope, rationale, owner, expiry/revisit trigger, and effect on experimental conclusions. |
| DEP-CURRENT-005-O4 | Never conceal a downgrade. |
