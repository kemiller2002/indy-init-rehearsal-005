# NR-PF-014

Derived from baseline requirement `PF-014` (Live integration acceptance). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Acceptance criterion |
|---|---|
| PF-014-O1 | At defined integration checkpoints and before release acceptance, run a real GitHub provider test against the approved repository and pinned catalog. |
| PF-014-O2 | Confirm actual network communication, correct request-to-response association, three historical investigation reconstructions, expected versions/digests, and deployed application behavior. |
| PF-014-O3 | Record repository ref, source SHA, run ID, and provider mode. |
| PF-014-O4 | Never claim live success from mocks. |
