# NR-PF-017

Derived from baseline requirement `PF-017` (Failure isolation). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Statement |
|---|---|
| PF-017-O1 | Report failures by domain, UI, provider contract, or live integration layer. |
| PF-017-O2 | A provider outage must not make offline UI/domain checks fail; an offline pass must not waive a failing integration gate. |
