# NR-AR-020

Derived from baseline requirement `AR-020` (Selective enforcement). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Acceptance criterion |
|---|---|
| AR-020-O1 | Retain the demonstrated four-tier architecture brief as default guidance. |
| AR-020-O2 | Do not add per-step Ordo architecture enforcement, typed agent records, or executable decision gates without a measured incremental correctness benefit that justifies cost and false rejections. |
| AR-020-O3 | Typed domain models and security/acceptance boundaries remain mandatory where independently justified. |
