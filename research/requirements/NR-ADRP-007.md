# NR-ADRP-007

Derived from baseline requirement `ADRP-007` (Deterministic graph and timeline). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Statement |
|---|---|
| ADRP-007-O1 | Render graph edges only from canonical projected relationships; deterministic layout seeded by stable IDs, with accessible textual alternative. |
| ADRP-007-O2 | Timeline sorts by canonical sequence/version, not wall-clock alone. |
| ADRP-007-O3 | Entity selection opens the same inspector from graph, timeline, search, and comparison. |
| ADRP-007-O4 | Do not implement independent causal inference, synthetic confidence, or implicit event mutation. |
