# NR-UI-013

Derived from baseline requirement `UI-013` (Cross-view consistency). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Statement |
|---|---|
| UI-013-O1 | Dashboard, graph, timeline, evidence inspector, comparison, and report MUST refer to the same investigation ID and authoritative aggregate version. |
| UI-013-O2 | On a successful command, refresh dependent views atomically from the new projection. |
| UI-013-O3 | Stale data MUST be identified, not silently mixed across versions. |
| UI-013-O4 | Deep links MUST resolve or fail with a useful recovery state. |
