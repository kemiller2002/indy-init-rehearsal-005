# NR-AR-007

Derived from baseline requirement `AR-007` (Evidence-backed acceptance). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Acceptance criterion |
|---|---|
| AR-007-O1 | Every PASS must cite the actual test, assertion, artifact, environment, and source SHA. |
| AR-007-O2 | Distinguish PASS, FAIL, PARTIAL, BLOCKED, and NOT_RUN; never infer PASS from code presence or a mock result. |
