# NR-UI-027

Derived from baseline requirement `UI-027` (Contextual domain-authorized actions and draft clarity). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Statement |
|---|---|
| UI-027-O1 | Present actions in the context of the relevant hypothesis, evidence, or corrective action, not as an engine command console. |
| UI-027-O2 | Offer only actions authorized by the F# domain engine, with clear reasons for unavailable actions where useful. |
| UI-027-O3 | Require reason/basis and confirmation when the domain contract requires them. |
| UI-027-O4 | Clearly distinguish exploratory draft changes, unsaved state, and committed authoritative changes; provide visible discard and consequence review. |
| UI-027-O5 | Never introduce persistence or mutation into a read-only rehearsal without explicit scope approval. |
