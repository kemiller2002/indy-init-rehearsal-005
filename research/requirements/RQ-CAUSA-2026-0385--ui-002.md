# RQ-CAUSA-2026-0385

Derived from baseline requirement `UI-002` (Interactive causal graph). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Statement |
|---|---|
| UI-002-O1 | Render nodes and typed relationships for observations, hypotheses, evidence, contradictions, causal assertions, and contributing/root causes as represented in the domain projection. |
| UI-002-O2 | Clicking/tapping or keyboard-selecting a node MUST open its detail and provenance. |
| UI-002-O3 | Visually distinguish established, proposed, contradicted, and unresolved relationships using both labels/shapes and color. |
| UI-002-O4 | Graph layout MUST be deterministic for identical inputs, support zoom/pan and fit-to-view, and provide a fully accessible textual relationship list. |
| UI-002-O5 | No browser-generated causal inference or fabricated edges. |
| UI-002-O6 | Large graphs MUST remain usable without blocking input. |
