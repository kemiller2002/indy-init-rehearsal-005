# NR-UI-005

Derived from baseline requirement `UI-005` (Evidence inspector). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Statement |
|---|---|
| UI-005-O1 | Display source/provenance, capture/record timestamps, original evidence content or safe reference, interpretation, reliability/limitations where defined, and explicit links to supporting and contradicting hypotheses. |
| UI-005-O2 | Never alter or overwrite the original evidence when interpretations change. |
| UI-005-O3 | Sanitize untrusted text/URLs; clearly label missing provenance. |
| UI-005-O4 | Enable navigation from graph, timeline, and hypothesis comparison. |
