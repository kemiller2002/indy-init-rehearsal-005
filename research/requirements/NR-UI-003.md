# NR-UI-003

Derived from baseline requirement `UI-003` (Investigation timeline). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Statement |
|---|---|
| UI-003-O1 | Show chronological event history with event type, actor/source where available, event timestamp, and domain version/sequence. |
| UI-003-O2 | Provide filtering by category and a detail view showing before/after semantic changes when derivable. |
| UI-003-O3 | Preserve immutable history; clearly distinguish event time from recorded time and order by canonical event sequence where timestamps conflict. |
| UI-003-O4 | Selecting a timeline item MUST link to affected domain entities when possible. |
