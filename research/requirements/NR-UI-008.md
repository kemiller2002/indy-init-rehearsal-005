# NR-UI-008

Derived from baseline requirement `UI-008` (Hypothesis comparison). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Statement |
|---|---|
| UI-008-O1 | Allow side-by-side comparison of at least two hypotheses, showing claim, current state, supporting evidence, contradicting evidence, assumptions, unknowns, and verification criteria when defined. |
| UI-008-O2 | Counts and labels MUST be projection-derived. |
| UI-008-O3 | Provide a stacked responsive alternative on narrow screens. |
| UI-008-O4 | Do not rank hypotheses or display numeric confidence unless the domain engine explicitly defines and supplies that semantics. |
