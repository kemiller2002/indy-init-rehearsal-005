# NR-WDL-002

Derived from baseline requirement `WDL-002` (No duplicate engine). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Statement |
|---|---|
| WDL-002-O1 | Causa must not introduce a second general-purpose graph layout implementation or maintain fixed SVG coordinates for domain nodes and edges when the existing workflow engine supports them. |
| WDL-002-O2 | An explicitly documented temporary fallback requires approval and cannot be represented as satisfying this requirement. |
