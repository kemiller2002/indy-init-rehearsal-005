# NR-AR-026

Derived from baseline requirement `AR-026` (Shared HTTP cache). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Statement |
|---|---|
| AR-026-O1 | Investigate a provider-neutral, opt-in cache policy at the Limen HTTP boundary with explicit freshness, invalidation, security, and stale-data semantics; do not silently use stale results for authoritative decisions. |
| AR-026-O2 | Place implementation in Limen's documented Praxis input path after owner/contract verification. |
