# NR-WDL-003

Derived from baseline requirement `WDL-003` (Typed domain-to-graph projection). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Statement |
|---|---|
| WDL-003-O1 | Define a typed F# adapter that projects authoritative causal assertions, outcomes, hypotheses, cause roles (root cause, trigger, contributing factor, enabling condition), and evidence counts into graph nodes and relationships. |
| WDL-003-O2 | The projection must not invent causal claims, change domain states, or perform domain inference. |
