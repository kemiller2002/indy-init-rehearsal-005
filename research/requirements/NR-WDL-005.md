# NR-WDL-005

Derived from baseline requirement `WDL-005` (Data-driven layout). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Statement |
|---|---|
| WDL-005-O1 | Node placement and edge geometry must be computed from graph input and supported constraints, not from hardcoded coordinates for specific investigations. |
| WDL-005-O2 | Layout must remain valid for zero, one, many, disconnected, and cyclic graphs where the domain permits them. |
