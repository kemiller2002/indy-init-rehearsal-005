# NR-VER-005

Derived from baseline requirement `VER-005` (No unreviewed prereleases). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Statement |
|---|---|
| VER-005-O1 | Do not adopt alpha, beta, RC, unpublished source, or unverified local builds merely because they are newer. |
| VER-005-O2 | Such use requires explicit approval, provenance, and the same compatibility and security gates. |
