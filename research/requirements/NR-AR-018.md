# NR-AR-018

Derived from baseline requirement `AR-018` (Fail-closed acceptance). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Acceptance criterion |
|---|---|
| AR-018-O1 | Missing credentials, unavailable external verification, unsigned approvals, stale evidence, failed gates, or unverified deployed artifacts must produce BLOCKED or FAIL as appropriate. |
| AR-018-O2 | An agent cannot override these outcomes with narrative. |
