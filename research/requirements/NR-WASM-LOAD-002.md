# NR-WASM-LOAD-002

Derived from baseline requirement `WASM-LOAD-002` (Loading icon). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Statement |
|---|---|
| WASM-LOAD-002-O1 | Provide a recognizable Causa application icon/mark on the loading screen, with an accessible text equivalent. |
| WASM-LOAD-002-O2 | A subtle CSS-based loading indicator MAY accompany it; honor prefers-reduced-motion. |
| WASM-LOAD-002-O3 | Do not require JavaScript animation or a separate animation library. |
