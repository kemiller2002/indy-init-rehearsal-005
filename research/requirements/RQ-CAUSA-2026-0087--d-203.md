# RQ-CAUSA-2026-0087

Derived from baseline requirement `D-203` (Static hosting). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Statement |
|---|---|
| D-203-O1 | GitHub Pages/static hosting is a target where practical. |
| D-203-O2 | The product may later use service-backed deployment without changing domain semantics. |
| D-203-O3 | Because static hosting cannot answer arbitrary paths, routes are hash-based (`index.html#/...`), with relative links and no `<base href>`. |
| D-203-O4 | A reloaded or pasted deep link therefore never 404s (R9.7, P34.18; Limen DF-LIMEN-2026-0006; Praxis SAF-URL-6). |
| D-203-O5 | A later service-backed deployment may move to path routes only if it keeps every hash link working through legacy redirects. |
