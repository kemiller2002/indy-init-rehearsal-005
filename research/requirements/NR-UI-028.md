# NR-UI-028

Derived from baseline requirement `UI-028` (Human-centered empty, loading, and failure states). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Statement |
|---|---|
| UI-028-O1 | For empty catalogs, unavailable investigations, failed loads, disconnected providers, and invalid data, state in plain language what happened, whether user work is retained, and what action is possible next. |
| UI-028-O2 | Avoid showing repository branches, schema internals, raw state codes, or implementation traces in the primary message. |
| UI-028-O3 | Expose technical diagnostic details through Administration. |
| UI-028-O4 | Loading copy must describe the user's task and never fabricate progress. |
| UI-028-O5 | Preserve fail-closed behavior and truthful blocked/unknown statuses. |
