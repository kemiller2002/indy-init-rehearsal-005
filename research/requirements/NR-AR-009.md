# NR-AR-009

Derived from baseline requirement `AR-009` (Negative-control testing). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Acceptance criterion |
|---|---|
| AR-009-O1 | Critical tests must include a deliberately invalid case that fails for the intended reason. |
| AR-009-O2 | Detect tests that pass regardless of implementation or verify mere existence rather than behavior. |
