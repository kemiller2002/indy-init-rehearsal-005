# NR-VER-001

Derived from baseline requirement `VER-001` (Latest compatible verified release). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Statement |
|---|---|
| VER-001-O1 | Each build MUST use the newest available stable, published, compatible release of every applicable Echelon system at the time the build baseline is locked. |
| VER-001-O2 | Applicable systems include Praxis, Ordo, Dokimos, Percepta, Forma, Forma Studio/workflow layout, Limen, Folio, and any actually integrated Echelon dependencies. |
| VER-001-O3 | Discover the real owner and release channel for each; do not invent a release or assume every system is a runtime dependency. |
