# NR-UI-012

Derived from baseline requirement `UI-012` (First-run guidance). Each obligation is carried verbatim as the criterion that bears its id.

| ID | Statement |
|---|---|
| UI-012-O1 | Offer a dismissible, replayable guided tour using the frozen synthetic investigations. |
| UI-012-O2 | Explain observations, hypotheses, evidence, contradictions, causal conclusions, and verification in context. |
| UI-012-O3 | Users MUST be able to skip the tour and start working immediately. |
| UI-012-O4 | Tour progress MUST NOT mutate frozen data or block accessibility. |
| UI-012-O5 | Persist dismissal only with an appropriate non-sensitive preference store. |
